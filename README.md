# Phonker Loader

Консольный загрузчик видео и музыки с YouTube, Twitch и других сайтов (всё, что умеет yt-dlp).
Один exe, ничего ставить не нужно. Работает на Windows 10/11, 64 бит.

## Использование

Запусти `PhonkerLoader_vX.Y.Z.exe` и вставь ссылку прямо в меню (или выбери `[1]`).

- **Качество**: от максимального до 360p или «Только звук (MP3)» с обложкой и тегами.
  До 1080p видео сохраняется в H.264 + AAC, такой файл открывается в любом плеере.
- **Фрагмент**: `1:15-2:40`, `1:15` (до конца), `-2:40` (с начала), Enter для всего видео.
- **Плейлисты**: если дать ссылку на плейлист, он скачается в отдельную папку.
- **Ctrl+C** во время загрузки отменяет её. В меню Ctrl+C закрывает программу.

Файлы попадают в папку `Downloads` рядом с exe. Если туда нельзя писать (например, exe лежит
в Program Files), они попадают в `Видео\Phonker Loader`. История хранится там же
в скрытом `history.json`.

## Cookies (необязательно)

Большинство видео качается без входа в аккаунт. Cookies нужны, только если сайт пишет
«подтвердите, что вы не бот», видео 18+ или доступно только спонсорам.

1. В браузере, где ты вошёл в YouTube, установи расширение «Get cookies.txt LOCALLY».
2. Открой youtube.com и экспортируй cookies в файл.
3. В программе выбери `[5] Cookies` и укажи путь к файлу (файл можно просто перетащить в окно).
   Вместо этого можно положить `cookies.txt` рядом с exe.

Подходят форматы Netscape (`cookies.txt`) и JSON. Программа читает копию файла и никогда
не меняет оригинал. Путь сохраняется в `settings.json` рядом с exe. Файл cookies никуда
не отправляется, кроме самого сайта, с которого ты качаешь.

**Никому не передавай свой файл cookies**: в нём лежит доступ к твоему аккаунту.

## Куда программа пишет на диск

- `%TEMP%\PhonkerLoader\…`: утилиты (yt-dlp, ffmpeg, deno) и недокачанные части на время работы.
  Папка удаляется при выходе, в том числе при закрытии окна крестиком. Если ПК выключили
  посреди загрузки, остатки удалит следующий запуск.
- `%LOCALAPPDATA%\PhonkerLoader\`: появляется только после пункта «Обновить yt-dlp» (около 18 МБ).
- `settings.json` рядом с exe: появляется, только если указать cookies.

## Сборка

Нужен Go 1.22+.

1. Положи `yt-dlp.exe`, `ffmpeg.exe` и `deno.exe` в папку `tools` (откуда скачать — в [tools/README.md](tools/README.md)).
2. Запусти `build.bat`.

Готовый exe появится в `dist\`. Он самодостаточный: для запуска не нужны ни Go, ни bat,
ни отдельные утилиты.

## Структура проекта

```
*.go, cmd/pack/      исходный код
build.bat            сборка
tools/               утилиты для сборки (в git не входят, только README)
dist/                готовый exe (в git не входит, выкладывается в Releases)
```
