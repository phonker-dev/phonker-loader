# Phonker Loader

Загрузчик видео и музыки с YouTube, TikTok, VK, Twitch, Instagram и сотен других сайтов.
Один exe, ничего устанавливать не нужно. Работает на Windows 10/11, 64 бит.
Есть встроенный Telegram-бот, чтобы пользователи качали видео через твой компьютер.

Короткая инструкция есть и в самой программе: вкладка «Справка».

---

## Быстрый старт

1. Скачай `PhonkerLoader_vX.Y.Z.exe` из раздела Releases и положи в любую папку.
2. Запусти его. Если Windows покажет «Windows защитила ваш компьютер», нажми
   «Подробнее» → «Выполнить в любом случае»: у программы нет платной цифровой подписи.
3. Откроется окно программы. Вставь ссылку на видео во вкладке «Скачать» (Ctrl+V), и поиск начнётся сам.
4. Выбери формат (первый — лучшее качество) и, если нужно, фрагмент. Нажми «Скачать».
5. Готово: кнопки «Открыть» и «Показать в папке». Файлы лежат в папке `Downloads` рядом с программой.

## Окно программы

| Вкладка | Что там |
|---|---|
| Скачать | Ссылка → формат → «Скачать». Можно качать несколько видео сразу, у каждого своя карточка и «Отмена». |
| Бот | Запуск и остановка бота, запросы на доступ, пользователи, журнал, токен, автозапуск. |
| История | Все загрузки с поиском. «Скачать снова» и «В папке». |
| Статистика | Сколько скачано и сколько весит: всего, сегодня, за 7 и 30 дней. |
| Настройки | Прокси, cookies, обновление yt-dlp, выход из программы. |
| Справка | Короткая инструкция. |

Разделы — слева, переключаются и мышкой, и Ctrl+1…6. Внизу слева строка состояния: работает ли бот,
есть ли запросы от пользователей, какой прокси, сколько скачано и не вышла ли новая версия yt-dlp. По ней можно кликать.
Ctrl+V из любого места окна сразу начинает поиск по ссылке.

Окно открывается через Microsoft Edge, который встроен в Windows 10/11: ничего ставить не нужно.
Закрыл окно — программа завершилась. Если запустить exe второй раз, откроется окно уже работающей программы.

Старый консольный интерфейс остался: запусти exe с параметром `--console`.
## Скачивание

- **Качество**: программа показывает только те разрешения, которые реально есть у видео.
  До 1080p видео сохраняется в H.264 + AAC, такой файл открывается в любом плеере.
- **Только звук (MP3)**: с обложкой и названием трека.
- **Музыкальные сайты** (SoundCloud, Bandcamp, Mixcloud, Яндекс Музыка, YouTube Music): программа сама
  понимает, что видео там нет, и предлагает MP3 или **MP4 с обложкой трека** (удобно для соцсетей).
- **Фрагмент**: поля «с» и «до», например с `1:15` до `2:40`. Можно заполнить только одно.
- **Плейлист**: если дать ссылку на плейлист, он скачается в отдельную папку.
- **Несколько загрузок сразу**: вставляй ссылки одну за другой, у каждой своя карточка.
  «Отмена» останавливает только свою загрузку, недокачанные куски удаляются сами.

## Если не качается

| Сообщение | Что делать |
|---|---|
| Нет соединения с сайтом | Включи VPN или прокси. v2rayN и Happ программа подхватывает сама. |
| Прокси не отвечает | Запусти v2rayN/Happ или выключи прокси: Настройки → Прокси → «Без прокси». |
| Сайт изменил защиту | Настройки → yt-dlp → «Обновить». |
| YouTube отклонил запрос (403) | Подожди пару минут или смени сервер VPN. Программа сама делает 3 попытки. |
| Требуется вход (18+, «я не бот», приватное видео) | Укажи cookies: Настройки → Cookies (см. ниже). |

## Настройки

### Прокси

По умолчанию стоит режим «Авто»:
- **Режим прокси**: v2rayN и Happ включают системный прокси Windows, программа видит его
  и пускает через него загрузки и бота.
- **Режим туннеля (TUN)**: системный прокси выключен, программа подключается напрямую,
  а трафик всё равно идёт через VPN.

Режим проверяется перед каждой загрузкой, так что переключаться можно на ходу.
Можно выбрать «Без прокси» или «Вручную» (`127.0.0.1:10809`, `socks5://127.0.0.1:10808`).

### Cookies (нужны редко)

Нужны, только если сайт требует вход: видео 18+, проверка «вы не бот», видео для спонсоров.

1. В браузере, где ты вошёл в YouTube, установи расширение «Get cookies.txt LOCALLY».
2. Открой youtube.com и нажми Export.
3. Настройки → Cookies → «Выбрать файл...» (или вставь путь к файлу и нажми «Указать»).

Подходят форматы Netscape (`cookies.txt`) и JSON. При выборе файла кнопкой рядом с программой
сохраняется его копия `cookies.txt`. Оригинал программа не меняет.
**Никому не передавай свой файл cookies**: в нём лежит доступ к твоему аккаунту.

### Обновление yt-dlp

YouTube регулярно меняет защиту, и yt-dlp за этим догоняет. При запуске программа проверяет,
не вышла ли новая версия. Если вышла, в шапке появляется подсказка. Обновить: Настройки → yt-dlp → «Обновить».

## Telegram-бот

Пользователи присылают боту ссылку, программа скачивает файл через твой прокси и отправляет его в чат.
Сервер и хостинг не нужны. Бот работает, пока открыто окно программы.

Обычному пользователю бот не нужен, поэтому в его версии про бота нет ничего: ни раздела, ни настроек.
Раздел «Бот» появляется, только если программу один раз запустить с параметром `--bot`
(или если токен бота уже указан в `settings.json` рядом с exe).

### Первый запуск (один раз)

1. В Telegram найди **@BotFather** (с синей галочкой) → `/newbot` → придумай имя
   и адрес, который заканчивается на `bot`. В ответ придёт токен вида `123456789:AAH...`.
2. Запусти программу с параметром `--bot`: нажми Win+R, вставь путь к exe в кавычках и допиши ` --bot`,
   например `"C:\Phonker\PhonkerLoader_v2.5.0.exe" --bot`, затем Enter.
   Откроется программа с разделом «Бот» — вставь токен и нажми «Сохранить». Дальше раздел будет виден всегда.
3. «Запустить». Ссылка на бота появится рядом со статусом, отправь её пользователим.
4. Напиши боту сам и нажми «Разрешить» у своего запроса: бот пускает только тех, кто в списке.

### Каждый день

- Открой программу → «Бот» → «Запустить». Или включи автозапуск («Бот» → «Настройки бота»):
  при входе в Windows откроется окно и бот запустится сам.
- На панели видно, сколько отправлено за сессию, что качается прямо сейчас, и все события.
- **Новый пользователь написал боту** — на панели появляется «Просят доступ» с кнопками «Разрешить» и «Отказать»,
  а на вкладке «Бот» — жёлтый значок. Запросы сохраняются: ответить можно и позже, даже при выключенном боте.
- «Остановить» — пользователи увидят «🔴 не в сети». «Перезапустить» — например, после смены прокси или токена.
- Закрыл окно программы — бот тоже остановился.

### Что видят пользователи бота

- **Закреплённое сообщение вверху чата**: «🟢 Online» или «🔴 Offline».
  Видно сразу, без захода в профиль.
- Кидают ссылку и получают видео с прогрессом скачивания прямо в чате.
- Под видео есть кнопка «🎵 Только звук», под mp3 — «🎬 Видео».
- Музыка с SoundCloud и похожих сайтов сразу приходит в MP3, под ней кнопка «🖼 MP4 с обложкой».
- Внизу чата постоянные кнопки «📜 Мои загрузки» (последние 15) и «❓ Как пользоваться».
- Лимит Telegram — 50 МБ на файл. Длинные видео бот сам отправляет в качестве пониже.

### Пользователи, журналы и статистика

- «Бот» → «Пользователи»: у каждого пользователя — сколько скачал и сколько это весит, когда был последний раз,
  язык, сайты, а по клику раскрывается **полная история всех ссылок**, которые он присылал. Там же
  «убрать доступ» / «вернуть доступ».
- «Бот» → «Журнал загрузок»: все загрузки через бота — кто, что, ссылка, размер, ошибки.
- «Бот» → «Панель» → «Журнал событий»: запуски, запросы на доступ, загрузки, ошибки связи.
  Хранится за всё время, а не только за текущий запуск.
- Вкладка «Статистика»: общий объём, свой и через бота.
Telegram сообщает боту только имя, юзернейм, ID, язык и наличие Premium.
Телефон, IP и местоположение бот не видит.

## Консольный режим

`PhonkerLoader.exe --console` открывает старый интерфейс с меню: всё то же самое, только с клавиатуры.
В нём бот останавливается по Enter и перезапускается по R.
## Какие файлы создаёт программа

| Где | Что | Можно ли отдавать другим |
|---|---|---|
| `Downloads\` рядом с exe | скачанные видео и скрытая история `history.json` | на твоё усмотрение |
| `settings.json` рядом с exe | прокси, путь к cookies, **токен бота**, список пользователей | **нет** |
| `cookies.txt` рядом с exe | копия cookies, если выбрать файл кнопкой | **нет** |
| `bot_data.json` рядом с exe | статистика и журнал бота, запросы на доступ | **нет** |
| `%TEMP%\PhonkerLoader\` | утилиты и профиль окна на время работы | удаляется само |
| `%TEMP%\PhonkerLoader\phonker.log` | журнал программы: пригодится, если что-то пошло не так | можно, личного там нет |
| `%LOCALAPPDATA%\PhonkerLoader\` | обновлённый yt-dlp, только после «Обновить» | — |

Делиться программой безопасно, если отдавать **только exe**.

### Как посмотреть программу глазами обычного пользователя

Все настройки и данные лежат рядом с exe, поэтому exe в пустой папке — это ровно то, что получит
человек, скачавший программу из Releases: без токена, без раздела «Бот», с пустой историей.

1. Создай пустую папку, например `C:\PhonkerLoader-проверка`, и скопируй туда exe из `dist`.
2. Запусти его оттуда. Копии из разных папок работают одновременно, твоя рабочая с ботом не мешает.
3. Чтобы начать «с нуля» ещё раз — удали в этой папке всё, кроме exe.

## Сборка из исходников

Нужен Go 1.22+.

1. Положи `yt-dlp.exe`, `ffmpeg.exe` и `deno.exe` в папку `tools` (откуда скачать —
   в [tools/README.md](tools/README.md)). Перед релизом стоит взять свежий yt-dlp.
2. Если что-то менялось, подними версию в файле `VERSION` и опиши изменения в `CHANGELOG.md`.
3. Запусти `build.bat`. Он упакует утилиты, прогонит тесты и соберёт
   `dist\PhonkerLoader_v<версия>.exe`.

```
*.go, cmd/pack/      исходный код
VERSION              номер версии
CHANGELOG.md         что менялось
build.bat            сборка
tools/               утилиты для сборки (в git не входят, только README)
dist/                готовые exe (в git не входят, выкладываются в Releases)
```
