# История версий

Номер версии хранится в файле `VERSION`, оттуда его берёт `build.bat`.

## 2.2.0

- Раздел «Бот» скрыт у обычных пользователей: программа остаётся простой качалкой.
  Включается в Настройках («Включить раздел «Бот»») или появляется сам, если токен бота уже указан.
- Проект теперь хранится в git: на GitHub попадает только код (см. `.gitignore`).

## 2.1.0

- Новый вид окна: навигация слева (Ctrl+1…6), строка состояния внизу слева (бот, прокси, скачано, yt-dlp),
  заголовок у каждого раздела, сплошная главная кнопка, сплошной прогресс-бар, метки статуса у загрузок.
  На странице «Скачать» под карточками — недавние загрузки с кнопкой «ещё раз».
  У бота — крупный статус ONLINE/OFFLINE и плитки со статистикой.
- Ctrl+V из любого места окна сразу начинает поиск по ссылке.
- Ники с «Zalgo» (десятки надстрочных значков) и невидимыми символами больше не ломают окно и консоль:
  имена чистятся, в том числе уже сохранённые.
- Исправлено: история бесконечно показывала «Загружаю...», если загрузок ещё не было.
- Закреплённый статус у друзей и описание бота — коротко: «🟢 Online» / «🔴 Offline».
- settings.json и bot_data.json читаются, даже если их пересохранили в Блокноте (с меткой BOM).

## 2.0.1

- Исправлено: окно могло потерять связь с программой («Failed to fetch»). Программа считала окно
  закрытым, как только завершался запущенный ей процесс Edge, хотя Edge иногда перезапускает себя
  (например, при установке обновления), а окно остаётся открытым. Теперь программа завершается,
  только если страница действительно перестала отвечать или сообщила, что её закрыли.
- Журнал программы (`%TEMP%\PhonkerLoader\phonker.log`): запуск, выход и его причина, текст ошибки
  при аварии. Открывается из Настроек кнопкой «Открыть журнал». Если программа в прошлый раз упала,
  окно сразу это покажет.
- Вместо «Failed to fetch» — понятное сообщение, что программа закрылась.

## 2.0.0

- Окно с вкладками вместо консоли: «Скачать», «Бот», «История», «Статистика», «Настройки», «Справка».
  Всё нажимается мышкой, бот работает в фоне, пока переключаешь вкладки. Окно открывается
  через встроенный в Windows Edge, ничего ставить не нужно. Консольный режим остался: `--console`.
- Несколько загрузок одновременно: у каждой своя карточка с прогрессом и кнопкой «Отмена».
  Отмена останавливает только свою загрузку.
- Бот: у каждого друга вверху чата закреплён статус «🟢 Бот в сети» / «🔴 Бот не в сети с …».
  Сообщение одно и то же: бот его правит, а не присылает новые.
- Бот: запросы на доступ, друзья, журнал и токен — прямо в окне, кнопками.
- Вторая копия программы не запускается, а показывает окно уже открытой.
- Исправлено: у прямых ссылок на видео без сведений о кодеке программа могла решить, что это музыка.

## 1.3.0

- Музыкальные платформы (SoundCloud, Bandcamp, Mixcloud, Яндекс Музыка, YouTube Music, Audiomack)
  определяются автоматически: сразу MP3 без попытки скачать «видео». Вместо видео — MP4
  со статичной обложкой трека, удобно для соцсетей.
- Бот: музыка сразу приходит в MP3, под ней кнопка «🖼 MP4 с обложкой», под видео-обложкой — «🎵 MP3».
- Бот: перезапуск клавишей R в панели, настройки перечитываются заново.
- Бот: короткие приветствие и описание вместо стены текста.
- Напоминание об обновлении yt-dlp теперь появляется, только если на GitHub действительно вышла
  версия новее. Раньше оно висело даже после обновления, если новых версий давно не было.
- Разделители `=====` растягиваются по ширине окна и больше не короче текста.

## 1.2.0

- Статистика: сколько файлов скачано и сколько они весят, за всё время, сегодня, за 7 и за 30 дней.
  Отдельно свои загрузки и загрузки через бота, плюс популярные сайты и самые активные друзья.
  Короткая сводка видна в главном меню.
- Бот: запросы на доступ больше не пропадают при перезапуске. На них можно ответить
  и без запущенного бота (Telegram-бот → Запросы на доступ). Друг получит «Доступ открыт»
  при следующем запуске.
- Бот: повторные запросы от тех, кому отказали, больше не беспокоят.
- Бот: Enter останавливает бота, даже если в этот момент висит вопрос о доступе.
- Автозапуск сам переключается на новую версию exe, если она лежит в той же папке.
- Главное меню: сводка сверху (сколько скачано, прокси, ждущие запросы), новые пункты
  «Статистика» и «Как пользоваться».
- После загрузки можно сразу вставить следующую ссылку, не выходя в меню.
- В истории сохраняется размер файла.

## 1.1.1

- Бот: панель вместо бесконечного лога в консоли, кнопки внизу чата вместо команд,
  в описании бота указан создатель.
- Консоль: каждый экран рисуется с чистого листа, итог последнего действия виден под заголовком.

## 1.1.0

- Полная переработка: 64-битная сборка (старая не запускалась на других ПК), размер 97 МБ вместо 324.
- Прогресс-бар, выбор качества по реально доступным форматам, MP3 с обложкой, плейлисты, фрагменты.
- Временные файлы удаляются при любом выходе, недокачанные части не попадают в Downloads.
- Cookies пользователь указывает сам (Netscape или JSON), оригинал файла не изменяется.
- Прокси: автоматически берётся из v2rayN и Happ.
- Telegram-бот для друзей: доступ по разрешению владельца, лимит 50 МБ, очередь,
  кнопки «Только звук» и «Видео», история загрузок, статус «в сети» / «не в сети», автозапуск.
- При ошибке 403 загрузка автоматически повторяется со свежими ссылками.
